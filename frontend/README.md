# Frontend

React + Tailwind frontend for the team task manager.

Create a `.env` file from `.env.example`, then run:

```bash
bun install
bun run dev
```

The app expects the backend API at:

```bash
VITE_API_URL=http://localhost:4000/api
```

Useful commands:

- `bun run dev`
- `bun run build`
- `bun run lint`

Run `bun run build` before deployment.
